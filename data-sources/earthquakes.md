## 格式相容與觀測值

實際 API 外層為 success／records.Earthquake，新版事件有 IssueTime、ValidTime、EarthquakeInfo、Intensity.ShakingArea，縣市欄位 CountyName、觀測狀態 InfoStatus。發生時間為帶 +08:00 的 ISO 格式；兼容舊版空白分隔的臺灣時間與 ReportDateTime／ReportTime。沒有報告時間時留空，不把發生或擷取時間冒充報告時間。

CountyName 可能一次列出多個縣市，依官方該列 AreaIntensity 拆分；舊版 AreaDesc 的縣市名稱亦接受。只有 InfoStatus=observe（或舊報告未提供此旗標的觀測欄位）會納入；estimate 等狀態不冒充觀測。最大觀測震度取官方區域／測站觀測值最大值，保留 5弱／5強／6弱／6強；未由規模推估。未列縣市不補零，不以測站名稱猜縣市。

驗證日期日曆／時區、未來時間、經緯度合法範圍、規模 0–10、深度 0–800 km、報告編號及震度格式。可選欄位缺失顯示未提供；必要座標或來源格式異常時拒絕該批更新。公開 JSON 僅有固定白名單欄位，不保存原始 API 物件、授權、圖片或波形網址。原文僅接受 HTTPS 官方 cwa.gov.tw／scweb.cwa.gov.tw 的指定報告路徑，無帳密、查詢參數或片段；UI／地圖彈窗皆使用文字 DOM。

去重採同一發生秒且經緯度各相差不超過 0.03 度的保守比對，保留兩類報告來源。較新官方報告優先；同時間優先顯著有感，不把舊報告的較大震度混入新修訂觀測。此為應用合併規則，不宣稱擁有跨所有格式的官方唯一事件識別碼；若來源未來更正發生秒或震央超過容差，可能無法自動辨識為同事件。

## 更新與失敗保護

`npm.cmd run update:earthquakes` 沿用 `.env.local`、`CWA_API_KEY`、`scripts/lib/cwa-env.mjs`，每類一次、20 秒逾時。兩類都成功且非空、全部驗證通過後才原子替換 `public/data/earthquakes.json`。任一失敗／空白、格式異常、舊檔損壞或時間倒退時不覆寫。失敗日誌僅使用本機受控訊息，不顯示秘密資訊。

一般 build 直接複製安全快照，沒有氣象署請求或開發代理。維護者更新後需重新 build／發布；訪客不需會員金鑰。網頁刷新只重讀網站 JSON，快取 5 分鐘、手動間隔 10 秒、12 秒逾時，拒絕舊快照覆蓋；超過 24 小時提示快照可能過期。沒有常駐程式、排程、預警、音效、推播或任何付費服務。

## 震央地圖

使用本地依賴 Leaflet 1.9.4（BSD-2-Clause，授權隨 public/licenses/leaflet.txt 發布）及 [OpenStreetMap 標準底圖](https://operations.osmfoundation.org/policies/tiles/)，保留可見著作權標示。HTTPS 標準圖磚網址、正常瀏覽器 User-Agent／Referer／HTTP 快取，不做代理、離線預抓、批次下載或繞過快取。僅在地震頁按需載入地圖，並取得當下可見範圍圖磚。

地圖標記與列表共用同一份篩選資料，半徑依規模，實／虛線代表報告類型；地圖顯示所有符合紀錄，列表每頁 8 筆。底圖可用性由外部服務決定，無保證；圖磚失敗顯示提示，列表與詳情不依賴底圖。大量事件的標記可能重疊，可縮放、點選列表定位；本階段沒有聚合或歷史時間軸。
