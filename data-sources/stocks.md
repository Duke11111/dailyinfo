# Phase 2A 股票基本資料來源

本專案是課程用的基本資料搜尋與本機自選清單。未存取即時行情、歷史價格、交易或付費服務。

## 正式來源及使用方式

| 範圍 | 正式 API | 資料集說明 |
| --- | --- | --- |
| 上市公司 | [t187ap03_L](https://openapi.twse.com.tw/v1/opendata/t187ap03_L) | [政府資料開放平臺 18419](https://data.gov.tw/dataset/18419) |
| 上市 ETF 基金 | [t187ap47_L](https://openapi.twse.com.tw/v1/opendata/t187ap47_L) | [政府資料開放平臺 157399](https://data.gov.tw/dataset/157399) |

[TWSE OpenAPI 規格](https://openapi.twse.com.tw/)列明上述兩個端點。政府資料開放平臺列提供機關為金融監督管理委員會證券期貨局，內容為證交所資料；標示免費，採[政府資料開放授權條款第 1 版](https://data.gov.tw/license)。依條款標示來源，本專案另行加工整理，不代表官方背書。行情資訊另有使用規範，本階段不延伸取用行情資料。

## 已匯入範圍

2026/10/19 18:56（臺灣時間）成功取得兩端點的全部回應，出表日期皆為 **2026/10/18**：

- 上市 ETF 基金 **272 筆**，使用基金代號、基金簡稱、基金中文名稱。來源涵蓋被動、主動、槓桿／反向、期貨及境外等基金類型，依這份上市基金資料表實際回傳範圍收錄。
- 共 **1,368 個不重複代號**，全部可搜尋，不是手工選出的熱門股票。

上市公司資料不是所有證券種類的完整證券主檔；不宣稱涵蓋特別股、權證、ETN、所有 TDR 證券代號、上櫃／興櫃、上櫃 ETF 或海外交易所股票。後續新上市、下市、更名等需重新匯入才會反映。自選中已保存的代號即使不在新快照仍保留，並標示「快照未收錄」。

`public/data/stocks.json` 包含精簡資料、原始回應 SHA-256、來源筆數、出表日期、匯入時間及實測標頭。未收錄不必要的負責人、住址、電話等公司資料欄位。

## CORS、頻率及請求限制

- 以 `Origin: http://127.0.0.1:5173` 實測兩端點均回應 HTTP 200，但未提供 `Access-Control-Allow-Origin`；不能假設瀏覽器可直接跨來源讀取。
- 這次回應未提供 `Cache-Control` 或數值型的 rate-limit 標頭；在本次查閱的正式規格及資料集頁面中未找到明確的數字配額，**不代表無限流或保證可用**。未做高頻率或壓力請求。
- 兩個政府資料集說明頁均標示更新頻率「每1月」。實際回應另有出表日期，因此 UI 分別顯示出表日期及快照匯入時間，不保證每日更新，更不稱為即時資料。
- 採維護階段靜態匯入：每次執行僅依序對兩端點各發出一次請求，20 秒逾時，不自動高頻重試；一般安裝／建置／搜尋不請求 TWSE。
- 網站只讀同來源 `/data/stocks.json`，10 秒逾時。之後每次打字皆在記憶體本地搜尋；每頁 20 筆，所有符合資料可翻頁查看。

## 維護及失敗行為

```powershell
npm.cmd run import:stocks
```

此命令無需金鑰或登入。兩份回應必須皆通過欄位、代號、分類、筆數、日期及重複代號檢查，才以同目錄暫存檔取代既有快照。任一下載／驗證失敗即非零結束，保留既有快照，不以少數示範股票或假資料替代。匯入成功後應檢查版本差異，再執行相關測試與建置。

網站目錄載入失敗時，搜尋顯示錯誤及重試入口，自選群組照常保留；可憑已保存的代號、名稱與類型管理現有清單。基本資料快照不包含價格、漲跌額、漲跌幅及成交量，UI 統一顯示「尚未提供」。
