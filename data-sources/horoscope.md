## 更新與日期保護

`npm.cmd run update:horoscope`，完成後重新 `npm.cmd run build` 才能把新快照納入正式發布。

使用兩個有界 worker，各星座一次 GET、15 秒逾時、不重試。驗證完整十二星座、每日類型、代碼、文字長度及有效日期。全部日期必須一致且符合更新開始時的 Asia/Taipei 日期；跨午夜、非當日、任一錯誤、舊檔損壞或時間倒退皆拒絕覆蓋。先寫暫存檔再原子替換最後有效快照。

本機第二階段候選版的首頁優先直接查詢所選星座，`/data/horoscope.json` 保留為完整十二星座的安全 fallback。既有 Node.js 快照更新、Schema 與發布管線不變；尚未提交或部署此整合。

瀏覽器只在進首頁、切換星座、手動更新、回前景或臺灣午夜檢查所選星座；不一次抓十二份，也不持續輪詢。當日即時資料快取五分鐘，失敗冷卻五分鐘，十二秒逾時且不自動重試。快照讀取獨立進行，不阻擋正常即時回應。多消費者合併請求；取消離頁消費者時，只有沒有其他消費者才中止共用傳輸。取消不消耗失敗冷卻。

每次回應驗證 MIME、長度、sign、period、真實日期與請求前後的臺灣今天；昨天、未來、格式錯誤與跨午夜回應不能冒充今日運勢。讀取時間與即時取得／快照擷取時間分開顯示；API 失敗、429、CORS／網路問題及逾時均使用固定安全訊息。fallback 非當日仍顯示原日期與明確警告，來源連結、英文原文、偏好與展開閱讀皆保留。沒有有效資料時明確顯示不可用。公開部署不需要金鑰。

2026-10-24 使用隔離 Chrome 155 驗證原官方端點可在跨域模式讀取十二星座當日資料；這是當時的瀏覽器證據，不保證供應商每日準時更新或永久 CORS 可用。詳見 `docs/DAILY-FRESHNESS.md`。

## 個人化與圖示

僅 `dailyinfo.horoscope.v1` 保存 `{version:1, defaultSign}`。使用者按儲存或設為預設才寫入；`viewSign` 僅存在頁面記憶體。略過不寫入，重新進入首頁還原永久預設。損壞設定與容量錯誤顯示提示，不刪除其他設定或資料。

十二星座使用 Unicode 星座符號與裝置字型繪製，不下載第三方圖片或 SVG，沒有外部圖示素材授權依賴。星座運勢僅供娛樂參考。
