# DailyInfo 期中展示指南

展示日期：2026/10/30。Phase 6B / v0.9.0。

## 系統目的與技術

DailyInfo 將天氣、自選股票、新聞及臺灣地震整合成繁體中文 Dashboard，減少在不同網站切換的時間。使用 Vite、原生 JavaScript ES Modules、CSS 變數與 Vitest，不需要登入或資料庫。

- **天氣**：瀏覽器直接向免費 Open-Meteo REST API 查詢，依上次選取的臺灣行政區代表座標顯示模式預報及七日展望。不是當地測站即時觀測。
- **股票**：Node.js 從 TWSE 公開 REST API 匯入上市股票／ETF 基本目錄、盤後收盤行情與可用歷史資料。瀏覽器搜尋靜態目錄、讀取 JSON 行情快照，不宣稱即時報價。
- **新聞**：Node.js 解析中央社五類官方 RSS，去除 HTML、保留標題／前言／時間及原文連結，輸出 JSON；不擷取新聞全文。
- **地震**：Node.js 向中央氣象署取得兩類官方報告並驗證、去重，輸出不含秘密資訊的 JSON。Leaflet 加上 OpenStreetMap 底圖呈現同一批地震的震央。不是地震預測或預警。

股票、新聞、地震共用各自既有服務的記憶體快取。每張首頁卡片獨立載入與顯示錯誤，避免單一來源失敗阻斷其他資訊。外部文字透過 DOM `textContent` 渲染；全站設定、地區、群組與收藏使用經驗證的 localStorage。

## 建議展示流程（約 5 分鐘）

1. 開啟首頁，介紹四張資訊摘要與各自的資料來源、交易／發布／發生時間及快照擷取時間。
2. 天氣卡片前往完整頁面，搜尋並選取縣市／鄉鎮市區，取得真實預報；回首頁確認沿用該地區及七日摘要。
3. 股票頁建立自選群組，搜尋 `2330`、`2454`、`0050` 並加入；示範跨群組管理與排序，回首頁查看盤後行情及群組切換。首頁群組選單只改變摘要顯示，不改寫股票頁上次選取的群組。
4. 新聞頁切換分類、關鍵字搜尋並收藏，再開原文；首頁顯示快照中最新五則，收藏仍由原本新聞頁管理。
5. 首頁點最近地震位置，直接開啟該筆詳情與震央；示範地區、規模、日期篩選，區分規模與最大觀測震度。
6. 設定頁切換深色、強調色與大字級，回首頁並重新整理，確認設定與個人資訊保存。

展示前先確認網路與各卡片標示的日期。快照較舊仍會誠實顯示；天氣 API 或地圖底圖失敗時可展示獨立錯誤處理及其他有效卡片。不要將瀏覽器重新整理描述成更新所有外部來源。

## 維護者更新資料

在專案根目錄分別執行既有指令，再檢查輸出及快照時間：

```powershell
npm.cmd run import:stocks
npm.cmd run update:quotes
npm.cmd run update:news
npm.cmd run update:earthquakes
npm.cmd run update:exchange
```

地震更新僅由本機 Node.js 腳本讀取既有 `.env.local` 的 `CWA_API_KEY`，訪客不需要此檔案或金鑰。不要把金鑰放在命令列、`VITE_` 變數、前端、公開 JSON 或任何提交中。各更新腳本在失敗時保留原有有效資料；沒有排程自動更新。更新成功後仍須重新建置並重新發布 `dist/` 才會影響公開網站。

行情取官方最後可取得的有效交易日，休市或尚未發布時日期可能早於今天。新聞只涵蓋目前 RSS 快照；地震只涵蓋已擷取報告，不是完整歷史資料庫。首頁超過 24 小時的快照會顯示可能過期提示，沒有把網頁讀取時間當作外部擷取時間。

## 在另一台電腦啟動正式建置

準備 Node.js 24 LTS 與專案檔案（含 `package-lock.json`、`public/data/`，不要攜帶 `.env.local`、`node_modules/`），在專案目錄執行：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run preview -- --port 4173 --strictPort
```

用瀏覽器開啟 `http://127.0.0.1:4173/#/overview`。本機 preview 用於驗證正式產物，不是長期公開網站服務；不能直接雙擊 `dist/index.html`。老師只查看已附快照時，不需 CWA 帳號／金鑰；天氣查詢、新聞原文與地圖底圖需要網路。localStorage 以網址來源區分，換電腦、瀏覽器或連接埠不會自動同步群組與收藏。

## 公開網址部署方案（僅說明，尚未執行）

1. 選擇支援 HTTPS 與靜態網站的託管環境，先自行確認免費額度、流量及使用條款；本次沒有註冊、購買、推送或發布。
2. 建議部署於網域根目錄。若平台要求子目錄，先依實際路徑設定 Vite `base` 再建置，確認 JS、CSS 與 `data/*.json` 路徑皆能取得。
3. 在本機更新需要的公開快照，執行測試與 `npm.cmd run build`。只上傳 `dist/` 內容，勿上傳專案根目錄或 `.env.local`。
4. 保留快照中的官方來源、日期與授權資訊；地圖保留 Leaflet／OpenStreetMap 標示並遵守底圖政策，不大量預抓或離線下載底圖。
5. 驗證 HTTPS 首頁、六個 hash 路由、三份 JSON 快照、天氣跨來源請求、新聞原文連結及地圖。Hash 路由無須為各模組配置伺服器改寫。
6. 之後更新資料時重新建置／上傳，並讓公開 `data/*.json` 使用可重新驗證的快取策略，避免 CDN 長時間保留舊快照。本機 CWA 金鑰不應交給靜態託管端或訪客。

本階段不包含 CI/CD、自動排程、公開服務建立或跨裝置同步。
