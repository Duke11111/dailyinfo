## 稽核與改善

| 原狀 | 原因／影響 | 本次修正 |
| --- | --- | --- |
| 淺色輔助文字／邊框層次失效 | 後方 :root 的 --muted:var(--muted)、--border:var(--border) 產生自我引用循環；Chrome 實際計算值為空 | 移除循環宣告，保留原語意變數；提高淺色輔助與錯誤文字對比 |
| 首頁先顯示完整星座長文 | 主要四項摘要被推至下方；首次 1440px 對照 grid 頂端約 909px | 改為說明、精簡今日行程、四項摘要、完整星座；首次修後約 439px，所有來源、日期與說明保留 |
| 各元件圓角、留白、按鈕規格不一 | 跨頁視覺不連貫，小型按鈕不利觸控 | 新增獨立 ui-polish.css：共用卡片／控制項 token、輕陰影、留白與 44px 主要按鈕觸控高度 |
| 手機七個導覽占三列 | 壓縮內容可視空間 | 改四欄兩列、圖示置於文字上；保留所有入口，大字仍可用 |
| 資訊文字過小或數據易讀性不足 | 來源閱讀、比對價格較吃力 | 輔助文字與行高調整、價格 tabular-nums、資訊表格間距統一 |
| 手機大字股票長成交金額折行 | 原兩欄詳情難容納長數字 | 僅此窄螢幕大字情境改單欄，來源連結獨立留距；不改圖表或價格邏輯 |

新樣式以現有 accent、focus、surface、border 等變數為基礎，不把五種強調色改寫成森林綠。沒有新增動畫、Hero、資料或套件；保留 reduced-motion 規則，並在減少動態時取消既有模組卡 hover 位移。
